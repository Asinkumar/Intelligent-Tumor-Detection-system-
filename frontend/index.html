Column order matters. The model receives a positional array, so swapping two columns produces a valid-looking request with meaningless results. Verify the order before uploading, or use the manual entry form which labels each field.
MODEL PERFORMANCE

Classification Model & Evaluation

The production classifier is a calibrated Support Vector Machine evaluated on an untouched held-out test set. Model selection prioritised malignant-case recall over raw accuracy to minimise missed cancers.

Model Architecture

Input 30 features
→
Scaling StandardScaler
→
Classifier SVC (RBF)
→
Calibration Sigmoid (cv=5)
→
Output Malignant prob.
  • Class weighting Balanced
  • Decision threshold 0.50
  • Explainability SHAP (permutation)
  • Training data 455 real records
  • Synthetic augmentation CTGAN evaluated, not used

Clinical Error Priority

1 False negative

A false negative is a malignant tumour classified as benign. Model selection and promotion gates rank recall above accuracy, so this count can never silently increase.

Reproducible Pipeline

01 Data 569 records, 30 features, no missing values
02 Split 80/20 stratified, leakage-free
03 Synthetic CTGAN, 1000 rows generated
04 Baselines 5 classifiers, 5-fold CV
05 Tuning Grid search on 3 models
06 Selection Recall-first, real-only won
07 Explainability SHAP global and local
08 Monitoring Drift detection and guarded retraining

Reported figures come from a single stratified split on the Wisconsin Diagnostic Breast Cancer dataset. They are research results on a benchmark dataset, not validated clinical performance.
